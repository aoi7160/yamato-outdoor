# 社内版(月次事業報告書)の書式

読み手はCEOとメンバー。**3分で「今月どうだったか・来月何をするか」が分かる**ことを優先する。
社内の言葉(コミット・PR・GA4など)は使ってよい。ただし数字には必ず出どころと時点を添える。

---

## 1. 構成

```
YAMATO OUTDOOR 月次事業報告書(2026年◯月)
作成日 / 対象:全ブランチ・各部の報告・P&L台帳

リード(3文):今月の結論 → 一番大きな成果 → 一番大きな課題

KPIタイル(4つ):売上(確定) / 営業利益 / 作業時間 / 時間あたり利益
   ※P&Lが無い月(立ち上げ期)は:作業件数 / 公開記事 / PV / 登頂

1. 月次P&L            表(当月・前月・累計・計画)+ 注記(未確定・未回収・按分)
2. 計画と実績         事業計画書の月次目標との対比表。±30%を超えた項目に一言の理由
3. 今月やったこと     分野別(デザイン・機能・SEO計測法令・記事・営業・計画)。日付・内容の表
4. 数字の動き         PV・流入元・CV(データ分析部の確定値)。グラフは2系列まで
5. 作業時間           区分別の横棒グラフ。計画した配分との差
6. 登頂記録           表+写真(社内版は顔写真も可)
7. 来月の重点         経営企画の案のうち、CEOが承認したものだけ(優先3つ)
8. 決めてほしいこと   CEOの判断待ちの論点(あれば)
```

## 2. 図と表の使い分け

- 日別・月別の推移 → 縦棒(`bars`)。2系列まで(例:main反映 / 未マージ、確定 / 未確定)
- 内訳・ランキング → 横棒(`hbars`)。多い順に並べてから渡す
- 5つ以下の数字の比較・属性が混ざるもの → 表
- 1つか2つの数字 → 文章かKPIタイル
- 注意してほしいこと(目標の見立て・リスク) → `box`(薄い黄色の枠)

配色は `report_pdf.py` に固定してある(緑 `#23865a` と黄土 `#c9822b`。色覚多様性の検証済み)。
**凡例と数値ラベルを必ず付ける**(色だけで区別させない)。

## 3. 書き方

- 結論を先に。「〜しました」で終わる経過報告ではなく「〜になった。理由は〜」
- 成果と同じ分量で課題を書く(Valueの「名実一体」)
- 数字の後ろに出どころ:「1,240PV(GA4・10/31確定)」
- 来月の重点は**最大3つ**。CEOが承認していない案は「経営企画の案(未承認)」と明記するか、載せない
