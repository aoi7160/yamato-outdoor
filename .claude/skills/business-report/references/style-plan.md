# 事業計画書の書式

計画を考えるのは社長室・経営企画、決めるのはCEO。事業報告部は**清書と数字の整合**を担う。
2026-09の「事業計画書(2026年10〜12月)改訂2」が基準(CEOの指示で2回作り直した経緯は lessons.md)。

---

## 1. 構成

```
事業計画書(2026年◯月〜◯月)
作成日(改訂番号)/ YAMATO OUTDOOR

この期間の目標        1文の目標(太字)+ 説明3文 + 指標×月末時点の表
目標についての見立て  box。達成の前提・リスク・届かなかったときの扱い(正直に)
達成の分解            例:PVの流入元別の内訳、収益源別の内訳(合計が目標と一致すること)
進め方                例:アフィリエイトのノウハウを得る手順(月ごと)
CVポイントの設計      サイトに既にある仕組み(src/lib/cv.ts)を確認してから書く
月別の計画            月ごとに「やること」「月末の達成基準」
時間の使い方          週の作業時間の配分表(合計が枠と一致すること)
リスクと対策          表
ほかに今やっておくべきこと / 中長期でやっておくと効くこと   表
```

## 2. 守ること

- **CEOが言った目標は、そのまま書く。** 無理だと思っても勝手に下げない。代わりに `box` で見立て(前提・リスク)を書く
  - 例:新規ドメインで「10月末に月1万PV」→ 目標はそのまま。見立てに「検索流入は立ち上がりに3〜6ヶ月かかるのが一般的。
    10〜11月のPVはSNS経由で作る必要がある」と書いた
- CEOが「現実的でない」と言った目標は、CEOの言葉どおりに置き換える(2026-09:無償/有償タイアップ → アフィリエイト月5万円に変更)
- **合計の検算**:内訳の合計 = 目標、時間配分の合計 = 週の枠。検算した値を本文に書く前に、スクリプトで足し算する
- 季節性を入れる(登山は7〜8月が山、11〜2月が谷。冬は雪山入門・冬の低山・トレーニング・セール・ふるさと納税)
- やらないことも書く(3ヶ月で手を広げすぎない)
- 計画書の数字は、月次P&Lの「計画」列とロードマップの「当面の目標」に転記する(3か所を一致させる)

## 3. 見た目

テーマ `internal`。社内向けのため色・グラフ可。対外に出すときは `style-external.md` の言い換え表を通し、
テーマを `external` にして作り直す(中身は同じでよい)。
