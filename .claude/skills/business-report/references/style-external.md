# 対外版(投資家・金融機関向け)の書式

2026-09の「8月・9月 事業報告書(対外用)」でCEOから「めちゃよかった」と評価された形が基準。
見本はCEOが提示した、あるNPO法人の年次事業報告書(平成27年度)。**会社や内容は参考にしない。書き方だけを真似る。**

---

## 1. 構成(この順で固定)

```
2026年◯月 事業報告書                         ← 表題(中央・明朝)
2026年◯月1日 〜 2026年◯月◯日                ← 対象期間(中央)
                       アウトドアメディア YAMATO OUTDOOR  ← 運営者名(右寄せ)

1　事業の成果                                 ← 見出しは全角スペースで区切る
   である調の文章を5〜8段落。1段落1話題。最後の段落で「次の期にやること」と「売上の状況」に触れる

2　事業に関する事項
(1)　大きな事業のまとまり
   ①具体的な取り組み
     ■施策名
       説明(である調・2〜3文)
         実績：数字(単位まで)            ← 「実績：」の行を必ず1つ以上
       写真(キャプション付き)・表
   ②…
(2)　…
(5)　取材活動(登頂)                         ← 形態・時期・山名・場所・内容の表+写真3枚
(6)　活動の経過                               ← 時期・内容の表(時系列)

3　収支の状況                                 ← 確定した数字だけ。売上が無い期は一文で正直に書く
```

## 2. 文体

- **である調**。「〜を行った」「〜を整備した」「〜を策定した」。です・ます調は使わない
- 主語は事業(「当期は」)。「私たちは」「AIが」は書かない
- 1文は60字以内を目安。数字には必ず単位
- 誇張しない。「業界初」「圧倒的」などの形容は使わない(`docs/persona.md` の使わない語も同じ)
- 未達・遅れも書く。隠すと次の期に信用を失う。書き方は「◯◯は◯月に持ち越した。理由は◯◯」

## 3. 削るもの(社内の言葉を出さない)

投資家・金融機関は開発の中身を見ていない。**次の言葉は対外版に出さない**(言い換え表)。

| 社内の言葉 | 対外版での書き方 |
|---|---|
| コミット・ブランチ・PR・マージ・行数 | 出さない(作業量を示したいときは「◯件の改修」程度) |
| microCMS | 記事管理のサービス |
| Astro・静的生成・SSG | 表示が速い静的なサイト構成 |
| Cloudflare Pages / Functions | 出さない(必要なら「配信サービス」) |
| 構造化データ・JSON-LD | 記事の内容を検索エンジンが読み取れる形で出力する仕組み |
| GA4・カスタムイベント | アクセス計測・読者の反応(スクロール、クリック、メール登録など)の計測 |
| SERP調査 | 検索結果の調査 |
| CV・soft CV | メール登録・LINE登録などの読者の反応 |
| ペルソナ | 想定読者(像) |
| AIエージェント・部 | 出さない(体制を問われたら「業務の手順を標準化し、少人数で運営できる体制」) |
| fps・LCP・CWV | 表示速度 |

## 4. 載せてよいもの・載せないもの

- 載せる:理念(Mission・Vision・Value。`docs/persona.md` から一字一句そのまま)、サイトの画面写真、
  ロードマップの4段階と次の期の計画(数字は事業計画書と一致させる)、山行の写真
- 載せない:個別のASP名と報酬額、メンバーの個人名、未確定の売上、社内の失敗の細部
- メンバーの顔が写る写真は**CEOが本人の同意を確認してから**(承認トレイ)

## 5. 見た目

- テーマ `external`(`scripts/report_pdf.py`)。明朝の本文、灰色の表見出し、ページ番号は中央に「- 1 -」
- 色は深緑の小見出しだけ。グラフは基本使わず、表と写真で見せる(見本に合わせる)
- サイトの画面写真は**トップ(パソコン)＋同(スマホ)**を横に並べる。撮り方は `data-sources.md`
- 写真は1行3枚・高さ60mm・キャプションは「山頂標柱にて」程度の短い名詞句

`templates/external-period.json` が2026年8・9月の対外版の構成そのもの(写真のパスだけ差し替える)。
