# SNS部の出力テンプレート(実例つき)

例の記事は、公開済みのサロモンの登山靴の記事(https://yamato-outdoor.com/mountain-climbing/boots/salomon-hiking-shoes/)。
例の文面は、その記事に書いてあること(結論は「シリーズ選びでほぼ決まる」・実レビューは岩湧山・ロー/ミッドの判断軸)だけから作った。
**記事に無い数字・体験は書いていない**(実測値を使うところは `【記事の実測値】` と書いてある。実際に作るときは記事から写す)。

## 1. 運用設計書(`content/sns/playbook.md`)

```markdown
# SNS運用設計書(最終更新:YYYY-MM-DD / SNS部)

## 目的
記事で確かめたことを、検索の外にいるP1・S1に届け、記事と再訪の口(LINE・メール)に送る。
KPI:SNSからのセッション → 読了 → soft CV。フォロワーは結果として見る。

## 媒体ごとの役割(SKILL 3-1)
| 媒体 | 相手 | 役割 | 型 | 頻度 | リンク |
|---|---|---|---|---|---|
| X | P1 | 判断材料を短く渡して保存させる | T1〜T4 | 平日1+週末1 | 本文 / リプライを4週ずつ試す |
| Instagram | S1・P1 | 世界観の発見・カルーセルで保存 | T5・T2・T6 | 週2 | プロフィール・ストーリーズ |
| Threads | P1・S2 | 記事の論点を会話に | T3・T1 | 週3 | 本文 |
| TikTok | S1 | 動画で認知 | T6動画 | 素材が月4本たまってから | プロフィール |
| Facebook | S2 | 記事告知の控え | T1 | 記事公開時 | 本文 |

## 始める順の推奨
X → Instagram+Threads → Facebook → TikTok(理由はSKILL 3-1)

## 時刻(仮説)
平日21:30〜22:30 / 金曜20:00〜22:00 / 週末6:00〜8:00。稼働4週で検証。

## PR表記
SKILL 3-5の表。迷ったら法務部。

## 計測
utm_source=<媒体>&utm_medium=social&utm_campaign=<slug>(命名はデータ分析部と合わせる。合意前は付けない)

## やらないこと
フォロー返し・懸賞・ハッシュタグの大量付け・事故や炎上に乗る投稿・他者の批判・体験の創作
```

## 2. プロフィール文(`content/sns/profiles.md`)

全媒体共通:**表示名「YAMATO OUTDOOR」/ アイコン `public/logo.svg` / リンク先 https://yamato-outdoor.com/(LINEの受け口ができたら切り替え案)**。
ハンドルの第一候補は全媒体同じ綴りの `yamato_outdoor`(空いているかは、アカウントを作るときにCEOが確かめる。空いていなければ全媒体で使える別の綴りを1つ決めて、全部それにそろえる)。

| 媒体 | 案(各上限の8割以内) |
|---|---|
| X | 関西の山で、使った装備と歩いたルートを記録する。【歩いた山名を3〜4つ】。量った数字と、合わなかった点まで書く。挑戦の、ベースキャンプになる。 |
| Instagram(名前欄) | YAMATO OUTDOOR|関西の登山 |
| Instagram(自己紹介) | 関西の山で使った装備と、歩いたルートの記録。<br>【歩いた山名を3〜4つ】。<br>挑戦の、ベースキャンプになる。 |
| Threads | Instagramと同じ自己紹介(同じアカウント系で一貫させる) |
| TikTok | 関西の山の装備とルートを、量った数字で。 |
| Facebook(基本データ) | 関西の山で実際に使った装備と、歩いたルートを記録するメディア。【歩いた山名を3〜4つ】。 |

**【歩いた山名】は、運営者が実際に歩いた山だけを入れる**(プロフィールで「同じフィールドを歩いていること」を証明するため。`docs/persona.md` 5章)。CEOに確認するまで空けておく。

書かないこと:「3回使ってから書く」などの方針・使用回数(`docs/persona.md` Editorial Policy 1)/ 盛った実績・資格の匂わせ / 使わない語。

## 3. 投稿の型の実例

**T1 記事の告知(X)**

```
サロモンの登山靴は、モデルより先に「シリーズ」で決まる。
X ULTRA 5 MID GORE-TEXで岩湧山を歩いて、効いたことと合わなかったことを書いた。
https://yamato-outdoor.com/mountain-climbing/boots/salomon-hiking-shoes/?utm_source=x&utm_medium=social&utm_campaign=salomon-hiking-shoes
```

**T2 実測の1数字(X)**

```
カタログ値と、量った重さは違った。
X ULTRA 5 MID GORE-TEX:【記事の実測値】(カタログ値【記事のカタログ値】)。
岩湧山の日帰りなら、この差は【記事の結論】。
```

**T3 判断の分かれ目(Threads・トピック「登山靴」)**

```
ミッドカットかローカットか。軸は「荷物の重さ」と「下りでの不安」の2つでいい。
日帰り・荷物5kg前後・整備された道ならロー。
荷物が重い、下りで足首が不安、岩や木の根が多いならミッド。
シリーズごとの早見表は記事に置いた。
https://yamato-outdoor.com/mountain-climbing/boots/salomon-hiking-shoes/
```

**T5 チェックリストのカルーセル(Instagram)**

```
1枚目:登山靴を買う前に確かめる4つ(文字は画像に入れる。サムネと違い、カルーセルは文字あり)
2〜5枚目:1枚1項目(記事の判断基準から)
6枚目:「詳しい比較はプロフィールのリンクから」+ YAMATO OUTDOOR
キャプション:本文3行+「プロフィールのリンクから記事へ」
ハッシュタグ(5個まで。山名は記事に出てくるものだけ):#登山靴 #岩湧山 #関西の山 #日帰り登山 #サロモン
画像の依頼:クリエイティブ部 4:5・6枚・ダークトーン(稼働後に発注)
```

**T6 登山の記録(Instagram)**

```
【体験を入れる:登った山・時刻・気温・その日に何を確かめたか。運営者の写真とメモから】
```

## 4. 投稿キュー(`content/sns/queue/<slug>.md`)

```markdown

- 記事の状態:公開済み / 承認トレイ(承認待ち)※未公開なら「公開後に有効」
- 記事のURL:https://yamato-outdoor.com/mountain-climbing/<category>/<slug>/(未公開なら予定。公開時にsitemap.xmlで確かめる)
- 材料:記事の結論 / 実測値(【要実測】が残っている数字は投稿でも空ける)/ 条件別の使い分け
- PR表記の判断:記事にASPリンク なし/あり → 投稿にASPリンクは入れない → 表記不要(SKILL 3-5)
- 最終更新:YYYY-MM-DD(記事の修正◯回目に合わせて更新)

## X(T1)
<本文>
- 字数:全角◯字 / 画像:なし

## Instagram(T5)
<カルーセルの構成とキャプション>
- 画像の依頼:4:5・◯枚(稼働後にクリエイティブ部へ)

<本文>
- トピック:<1つ>

- [x] 体験・実測を作っていない …
```

## 6. 承認トレイ「SNS投稿」(稼働モードだけ)

| プロパティ | 例 |
|---|---|
| 件名 | Xに「サロモンの登山靴」の記事の告知を投稿(11/9 21:45) |
| 状態 | 承認待ち |
| 依頼元 | sns |
| 種類 | SNS投稿 |
| 根拠 | 型T1 / 記事は公開済み(sitemap.xml・YYYY-MM-DD)/ PR表記:不要(投稿にASPリンクなし)/ 時刻:平日21:30〜22:30の枠(仮説) |
| 承認すると | CEOがXで投稿する(予約でも可)。SNS部が翌週に反応を記録する |
| 要約 | サロモンで迷う人に「シリーズで決まる」という結論を先に渡し、記事の早見表へ送る |

本文の json(1つだけ):

```json
{
  "links": [{ "label": "告知する記事", "href": "https://yamato-outdoor.com/mountain-climbing/boots/salomon-hiking-shoes/" }],
  "draft": {
    "label": "Xに投稿する文面(全角◯字)",
    "text": "サロモンの登山靴は、モデルより先に「シリーズ」で決まる。\nX ULTRA 5 MID GORE-TEXで岩湧山を歩いて、効いたことと合わなかったことを書いた。\nhttps://yamato-outdoor.com/mountain-climbing/boots/salomon-hiking-shoes/?utm_source=x&utm_medium=social&utm_campaign=salomon-hiking-shoes"
  },
  "images": []
}
```

画像付きの投稿は `images` に開けるURL(クリエイティブ部の納品)を入れる。URLが無ければ積まない。

## 7. 日報の自分の節

準備モード(例。数字は書き方の説明用):

```
### SNS部
- 結果:準備中(SOCIALSは全部空・11/09確認)。投稿キュー 11記事分33本・カレンダー W46〜W47
- 判断:承認トレイの記事2本が修正されたため、告知文の結論を記事に合わせて更新
- やったこと:紅葉期の六甲の交通をT4の下書きに(出典:公式・11/09確認)
- 依頼:CEO:Xのアカウントを作るときは profiles.md の一式を使ってください
```

稼働モード:

```
### SNS部
- 結果:X 先週5本、ブックマーク計N・リンククリックN(CEO提供・11/09)/ SNSからのセッションN(分析部)
- 判断:T2(実測の1数字)が中央値の2倍。T1は判断保留(4本)
- やったこと:今週の投稿5本を承認トレイへ。T2を週2本に増やした
- 依頼:クリエイティブ部:土曜のカルーセル6枚(4:5)
```
