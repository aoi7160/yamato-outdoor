# 取材質問の作り方(一次情報の引き出し方)

CEO(運営者)にしか答えられないことを、**10分で、具体的な事実として**答えてもらうための型。
ここで得た回答だけが、記事の体験の部分の材料になる(`docs/content-pipeline/rules.md` R1)。
コンテンツマップの「取材質問①〜⑤」がある記事は、まずそれを使い、足りない観点だけをこの型で足す。

---

## 1. 1問の型

```
Q<番号>(<記事のどのh2に使うか>)<聞きたい事実>は?
- 答え方:<単位・選択肢・「なし」でよい、など>
- 測り方:<実測なら道具と条件>
```

例:

```
Q2(h2「実測」)右足の登山靴の重さは?
- 答え方:g単位。サイズ(cm)も
- 測り方:キッチンスケールに靴だけを乗せる。中敷きは入れたまま。紐は通したまま
```

目印(`【要実測:…】` `【体験を入れる:…】`)の中身も、この型を1行に縮めて書く:
`【要実測:右足の重さ(g)とサイズ(cm)。キッチンスケール・中敷きと紐は付けたまま】`

## 2. 原則(悪い聞き方 → よい聞き方)

| 原則 | ✗ | ○ |
|---|---|---|
| 1問1事実 | 雨の日のグリップと蒸れはどうだった? | (2問に分ける)濡れた岩で滑った場面はあったか / 中が濡れた部位はあったか |
| 数値で答えられる | 重く感じた? | 自分で量った重さは何gか |
| 場面を特定する | 使ってみてどうだった? | 使った日付・山・天候・気温(分かれば)・何時間か |
| 合わなかった点を必ず聞く | (聞かない) | 買い直したい・人に勧めない理由が1つでもあれば何か |
| 比較は同じ条件で | 前の靴と比べてどう? | 同じ道(山・区間)を前の靴でも歩いたか。あれば区間名と、違いが出た場面 |
| 「なし」で答えられる | どんな工夫をしている? | 対策していることがあれば1つ。なければ「なし」 |
| 誘導しない | 蒸れなかったですよね? | 中が蒸れた・濡れたと感じた場面はあったか |
| 写真を1問 | (聞かない) | 次の写真はあるか:◯◯が写っているもの(無ければ撮れるか) |
| 回数・期間は聞かない | 何回使った? | (聞かない。記事に書かないため。`rules.md` R1-3) |

1記事5〜7問。8問を超えたら、記事の範囲が広すぎないかをSEO部に返す。

## 3. 記事の型ごとの質問集(ここから選んで直す)

### レビュー(単品・ブランド)

1. 使った日付・山・天候・気温(分かれば)・歩いた時間
2. 自分で量った重さ(g)とサイズ
3. 一番効いた場面(どの区間・どの路面で、何が起きたか)
4. 合わなかった場面(どの区間で、何が起きたか)/ 勧めない人がいるとしたらどんな人か
5. サイズ選び:普段の靴・服のサイズと、選んだサイズ。店で試したか
6. 雨・寒さ・汗など悪条件で使ったか。あれば何が起きたか
7. 写真:全体 / 実測している場面 / 使った場面

### 比較

1. 比べた製品それぞれを、同じ山・同じ区間で使ったか(使っていない製品は、比較表で実測の列を空ける)
2. それぞれの実測値(重さ・容量・寸法)
3. 同じ条件で差が出た場面(区間・天候)
4. 自分ならどれを選ぶか、その条件(「◯◯の山なら A」)
5. 選ばなかった製品の合わなかった点
6. 写真:並べた写真 / 実測

### ハウツー(やり方・選び方)

1. 自分がこの手順でつまずいたこと(1つ。日付・山)
2. 手順のうち、実際にやっていること・やっていないこと
3. 失敗したとき山で困ったこと(安全・時間・お金)
4. 使っている道具(製品名・持っていく量)
5. 写真:手順の途中 / 道具一式

### ルート記録

1. 歩いた日付・天候・気温・同行の有無(人数だけ)
2. 登山口までの交通(車・電車)と駐車場・最寄り駅の実際
3. 区間ごとの実際の時間(スタート・主要な分岐・山頂・下山)
4. 迷いやすい・危ない場所があったか(地点名と、どう迷いそうだったか)
5. 水場・トイレ・エスケープルートを実際に確かめたか
6. その日の装備で、足りなかったもの・要らなかったもの
7. 写真:分岐・標識 / 危ない場所 / 山頂

ルート記録は**体験が記事の大半**になる。上の回答がそろうまで、本文を書き始めない(`SKILL.md` 3-2)。
コースタイム・標高・交通の事実は、自治体・施設の公式で出典を取り、CEOの実際の時間と並べて書く(どちらかで代用しない)。

## 4. 置き場所

- 取材シート:非公開リポジトリ `../yamato-outdoor-editorial/content/pipeline/<slug>/interview.md`(`article-planner` の書式)
- 回答は公開リポジトリに書かない(取材の回答・実体験の記録は非公開。STANDARDS 5章)
- CEOへの依頼は日報の「依頼」に1行(「CEOへ:取材質問5問(<記事名>)。editorial/content/pipeline/<slug>/interview.md」)
