# PR・パートナーシップ部のテンプレート

スキル `yamato-partnership` の出力の型。すべて**下書き**で、送るのはCEOが承認したあと(L2)。
置き場所は非公開リポジトリ `aoi7160/yamato-outdoor-editorial` の `content/partnership/`。公開リポジトリには置かない。

```
content/partnership/
  contacts.csv            コンタクト台帳(1行=1先方)
  media-kit/YYYY-MM.md    媒体資料の下書き(月1で更新)
  proposals/YYYY-MM-DD-<先方の英字の略称>.md   提案書・依頼文の下書き
  log.md                  やりとりの記録(送った・返事・受領・返却。日付と要旨だけ)
```

---

## 1. コンタクト台帳(contacts.csv)

1行=1先方。**個人の名前・個人のメールアドレス・電話番号は書かない。** 書くのは、先方が公開している窓口(問い合わせフォームのURL・広報の代表アドレスの有無)だけ。
担当者の名前は、先方から返事が来て、CEOがやりとりを始めてから、CEOの判断で非公開リポジトリの `log.md` にだけ書く。

| 列 | 中身 | 例 |
|---|---|---|
| id | 英字の略称(提案書のファイル名に使う) | `rokko-shop-a` |
| 種類 | メーカー / ガレージブランド / 登山用品店 / 自治体 / 観光協会 / 山小屋・山の施設 / 団体(山岳会・遭難対策など) / 媒体 | 登山用品店 |
| 名称 | 正式名称 | (公式サイトの表記どおり) |
| 地域 | 関西なら府県と山域。関西外は「全国」 | 兵庫・六甲 |
| 窓口 | 公開されている窓口の種類とURL(問い合わせフォーム / 広報の窓口ページ / 取材申し込みページ) | 問い合わせフォーム https://… |
| 出どころ | 窓口を確かめたページのURLと確認日 | https://…(2026-11-01) |
| 組む理由 | P1にとって何が良いか1行(記事・送り出す・グッズのどれに効くか) | 六甲の記事に置く「下山後に寄れる店」の一次情報 |
| 提案の型 | 取材協力 / 情報・写真の提供 / サンプル貸与 / サンプル提供 / 共同企画 / タイアップ / 相互リンク・紹介 | 取材協力 |
| スコア | 下の採点の合計(25点満点) | 19 |
| 段階 | 候補 / 下書き済 / 承認待ち / 送付済(CEO)/ 返事あり / 進行中 / 完了 / 見送り | 候補 |
| 次の一手 | 何を・いつまでに | 11月の monthly で取材協力の依頼文を下書き |
| 更新日 | YYYY-MM-DD | 2026-11-01 |

### 採点(スキル3-2の5軸。各1〜5)

| 軸 | 5 | 3 | 1 |
|---|---|---|---|
| 読者との適合 | P1が月1〜2回の関西の日帰りで使う・寄る・歩く | 遠征(アルプス)やS1・S2向け | P1と関係が薄い |
| 関西の縄張り | 六甲・金剛・比良・大峰・岩湧山など、記事のある山域そのもの | 関西だが記事の無い山域 | 関西外 |
| 実現しやすさ | 小規模・地元・窓口が公開・媒体の規模を問わない | 中堅。窓口はあるが媒体の実績を見られる | 大手・代理店経由・実績が要件 |
| 一次情報の増え方 | 実測・取材・現地の情報が記事に増える | 写真や公式情報が増える | 記事は増えない(露出だけ) |
| リスクの低さ(高いほど安全) | 金銭なし・編集の独立が保てる | 物品の提供あり(表記で対応) | 対価あり・内容への関与を求められそう |

## 2. 媒体資料の下書き(media-kit/YYYY-MM.md)

**数字はデータ分析部の確定値だけ**(出どころと時点を書く)。立ち上げ期は数字を前に出さず、約束と一次情報で見せる(スキル3-1)。

```
# YAMATO OUTDOOR 媒体資料(YYYY年MM月時点・下書き)

## 1行で
関西の山を、働きながら月1〜2回歩く人のための、実測と実体験の登山メディア。
Mission:挑戦の、ベースキャンプになる。

## 読者
- 中心:関西在住・登山歴3年前後・月1〜2回の日帰り(六甲・金剛・比良)。年2〜3回アルプスへ
- 決め手にするもの:長く使った人の言葉、合わなかった点、自分で量った数字
(出どころ:docs/persona.md。読者調査の数字ではなく、編集方針として想定している読者)

## 編集の約束(Editorial Policy から、外に出してよいものだけ)
- 使ってから書く/数字は自分で量る/合わなかった点を同じ分量で書く/関西の固有名詞を出す/書きっぱなしにしない
- 提供・貸与を受けた道具は、記事の冒頭で明示する。内容の事前確認は、事実の誤りの指摘だけ受ける
(※「最低3回使う」という社内目標と使用回数には触れない。persona.md 4-1)

## 記事の見本
- <公開中の記事のタイトル>(URL)—— 何を実測したかを1行

## 数字(データ分析部の確定値・YYYY-MM-DD時点)
- 公開記事:◯本 / 月間PV:◯(GA4)/ 検索のクリック:◯(Search Console)
- 立ち上げ期の数字は小さい。小さいまま書く(盛らない)。目安を下回るあいだはこの節を「公開予定の記事と更新の頻度」に置き換える

## 一緒にできること
- 取材協力(店・施設・登山道の情報、写真の提供)
- サンプルの貸与・提供による長期の使用レビュー(掲載の約束はしない)
- 関西の山の企画(清掃登山・勉強会など。現地集合・現地解散)

## 連絡先
<CEOが決めた窓口。未定なら空欄>
```

## 3. 依頼文の型(proposals/)

すべての依頼文の冒頭に、社内用のメモ(先方には送らない)を置く。

```
<!-- 社内メモ(送らない)
先方:<contacts.csv の id> / 種類:<提案の型> / スコア:<点>
承認すると:CEOが<窓口>からこの文面を送る
金銭・物品:<なし / 貸与(返却期限) / 提供(金額の目安と出どころ)>
法務の確認:<済(日付)/ 不要の理由 / 未>
-->
```

### 3-1. 取材協力・情報提供の依頼(店・自治体・観光協会・山小屋)

```
件名:取材のお願い(関西の登山メディア YAMATO OUTDOOR)

<先方の正式名称> ご担当者様

関西の山の装備とルートを、実際に歩いて記録しているWebメディア「YAMATO OUTDOOR」を運営している<運営者名>です。
<URL>

<山域・テーマ>について記事を準備しています。<先方>の<具体的に知りたいこと:登山口の情報・営業期間・写真など>を、
記事の中で紹介させていただけないかと考え、ご連絡しました。

お願いしたいこと
- <1つ目:質問3つまで、または写真○枚の使用許可>
- <2つ目>

こちらからのお約束
- 費用はいただきません。お支払いもありません
- いただいた情報は、出典として<先方の名称>を明記します
- 公開前に、事実関係(営業時間・名称など)だけご確認いただけます

ご都合が合わない場合は、ご返信なしで構いません。
<署名:メディア名・運営者名・URL・連絡先(CEOが決めた窓口)>
```

### 3-2. サンプルの貸与・提供の依頼(メーカー・ガレージブランド)

```
件名:<製品名>の使用レビューのご相談(YAMATO OUTDOOR)

<メーカー名> 広報ご担当者様

関西の山を月1〜2回歩きながら、装備を実測して記録しているWebメディア「YAMATO OUTDOOR」の<運営者名>です。
<URL>(見本:<実測を載せた記事のURL>)

<製品名>を、<六甲・金剛などの山域>の<季節・条件>で使い、重量の実測と合わなかった点も含めて記録したいと考えています。
可能であれば、サンプルを<貸与 / ご提供>いただけないでしょうか。

進め方
- 使用期間:<目安>。返却が必要な場合は<期日>までに着払いで返送します
- 記事にする場合は、冒頭に「<メーカー名>から<貸与 / 提供>を受けて使用した」と明記します
- 公開前のご確認は、仕様・価格・名称など事実の誤りの指摘に限らせてください。評価と構成は編集部で決めます
- 掲載をお約束するものではありません。使って合わなかった場合は、その点も記事に書きます

<署名>
```

### 3-3. 共同企画・自治体連携の提案(清掃登山・登山道の情報発信など)

```
# <企画名>(提案書・下書き)

## ねらい
- 先方にとって:<登山道のマナー周知・来訪者の分散・地域の店の紹介 など、先方の課題の言葉で>
- 読者にとって:<次に行く日の判断材料が増える/山に出ていくきっかけ>
- YAMATO OUTDOORにとって:<関西の固有名詞の一次情報・送り出す(三階建ての3階)>

## 中身
- 何を:<記事◯本 / 現地集合の清掃登山1回 / 情報の定期更新>
- いつ:<時期。需要の山との関係(企画・編集会議部の需要カレンダー)>
- 役割:先方 <情報・場所・告知の協力> / YAMATO OUTDOOR <取材・記事・当日の運営>

## お金と物
- <なし>(立ち上げ期は金銭の授受が無い形から始める)

## 表記
- 記事:冒頭に「<先方>の協力を得て取材した」。対価があれば「PR」と広告主名(法務 rulebook 1-2)

## リスクと確認事項
- イベントを含む場合:現地集合・現地解散・参加費なしが既定(旅行業法の論点。コミュニティ部の企画書と法務の確認)
- 写真・ロゴの使用範囲
```

### 3-4. タイアップ(対価あり)の条件メモ

タイアップは**CEOの判断の材料**として作る。金額は自分で決めない。

```
# <先方>タイアップの条件メモ(下書き)

| 論点 | こちらの案 | 先方の希望(分かれば) | 法務の確認 |
|---|---|---|---|
| 形式 | 記事1本(実測レビュー) | | |
| 編集の独立 | 事前確認は事実の誤りだけ | | rulebook 2章 |
| 表記 | タイトル直下に「PR」と<先方名> | | rulebook 1-2 |
| 掲載期間・修正 | 期間の定めなし。事実の誤りは直す | | |
| 二次利用 | 先方の広告への転用は範囲と期間を別に決める | | |
| 競合排他 | 受けない | | |
| 金額 | <CEOが決める。相場を調べたなら、出どころと確認日と「推測」かどうか> | | |
| 支払い・請求 | <CEOが決める> | | |
| 成果の保証 | しない(PV・クリックを約束しない) | | |
```

## 4. 承認トレイ(README 11-1)

プロパティ:件名「<先方>へ<提案の型>の依頼を送る」/ 種類「外部への連絡」/ 依頼元 `partnership` /
根拠(1行に1つ:スコア・組む理由・法務の確認日)/ 承認すると「CEOが<窓口>から文面を送る。返事はlog.mdに記録」/ 要約。

本文のJSON:

```json
{
  "changes": [
    "<先方の正式名称>(<種類>・<地域>)へ、<提案の型>の依頼を送る",
    "金銭の授受:なし。物品:<なし / 貸与(返却期限)>",
    "法務の確認:<日付>に条件つきで可(編集の独立と表記の文面を反映済み)"
  ],
  "draft": {
    "label": "送る文面(CEOが自分の窓口から送る)",
    "text": "件名:…\n\n<本文>"
  },
  "links": [
    { "label": "先方の公開窓口", "href": "https://…" },
    { "label": "見本として添える記事", "href": "https://yamato-outdoor.com/…/" }
  ]
}
```

## 5. 日報の自分の節(STANDARDS 5章)

```
### PR・パートナーシップ部
- 結果:コンタクト台帳 候補14件(関西10・全国4)。進行中0・サンプル受領0(非公開リポジトリ contacts.csv、11/1時点)
- 判断:媒体の実績が小さいうちは金銭なし・地元・取材協力の型から。今月はスコア上位2件(六甲の店・金剛山の施設)を下書き
- やったこと:取材協力の依頼文2件を下書きし、法務に表記の確認を依頼
- 依頼:legal 依頼文2件の表記の確認 / analytics 媒体資料用の10月の確定値
```
