**ここにある報酬・条件は、調べた時点の目安。** 申請・リンク設計の前に、必ず各社の最新の規約・案件詳細で確かめ直し、
案件台帳の確認日を更新する。公式で確かめられなかったものは「二次情報」と書いてある(二次情報だけで判断を確定させない)。

## 2. 審査で見られる点(二次情報の共通項)

公式の審査基準を公開しているASPは見つからなかった(2026-11-01)。解説記事に共通して出てくる項目:

| 項目 | YAMATO OUTDOORの状態 |
|---|---|
| オリジナルの記事が5〜10本以上 | 公開はサロモンの記事など少数。承認トレイの10本が公開されれば満たす |
| 運営者情報 | `/about` あり |
| プライバシーポリシー | `/privacy` あり(外部送信の公表を含む) |
| 問い合わせ先 | **`CONTACT_URL` が空。** 申請前にGoogleフォームを入れる依頼を出す |
| コピー・転載が無い | 一次情報が前提なので満たす |
| 広告が多すぎない | buy-boxは1記事3つまで(SKILL 3-3) |
| 自己購入をしない | 多くのASPとAmazonで禁止 |

## 3. 法令・プラットフォームのルール

| ルール | 要点 | 出典・確認日 |
|---|---|---|
| ステマ規制(景品表示法・2023-10-01施行) | 広告であるのに広告と分からない表示が対象。規制される主体は広告主だが、アフィリエイト記事は広告主の表示になりうるので、記事冒頭に広告である旨を明示する(`pr-notice`) | https://www.caa.go.jp/policies/policy/representation/fair_labeling/stealth_marketing/(2026-11-01取得) |
| Googleのスパムポリシー「内容の薄いアフィリエイト サイト」 | 販売者の説明をそのままコピーし、独自の価値を加えずにリンクを置くページが対象。独自の商品レビュー・厳格なテスト・比較は「新たな価値」とされる | https://developers.google.com/search/docs/essentials/spam-policies?hl=ja(2026-11-01取得) |
| Amazonの表記 | 「Amazonのアソシエイトとして、YAMATO OUTDOORは適格販売により収入を得ています。」を目立つ場所に。`src/lib/site.ts` の `AMAZON_ASSOCIATE_NOTICE` で用意済み | 運営規約5条(上記URL) |
| リンクの属性 | ASPのリンクには `rel="sponsored nofollow"` が自動で付く(`src/lib/article.ts`・`src/lib/affiliate.ts`) | リポジトリ |
