# 法務のルールブック(論点ごとの判断表)

スキル `yamato-legal` の3章(判断の型)の詳細。条文・資料の出典と確認日は `sources.md`。
**ここに書いてあるのは、YAMATO OUTDOORの運用ルールと論点の整理であって、法的助言ではない。**
「専門家へ」と書いた行は、AIの判断で済ませずに、CEOが弁護士・弁理士・税理士・所管官庁に確認する前提で論点をまとめて渡す。

---

## 1. 広告表記(景品表示法・ステマ告示)

### 1-1. 誰が規制されるか(まず整理)

ステマ告示の対象は「事業者が**自己の供給する商品・役務**について行う表示」(景品表示法5条3号・運用基準第1)。
YAMATO OUTDOORは2つの立場を持つので、どちらの立場の表示かを先に決める。

| 立場 | 例 | 誰の表示になるか | YAMATO OUTDOORがやること |
|---|---|---|---|
| A. 第三者の商品の紹介者(アフィリエイター・媒体) | ASPのリンクがある装備の記事 | 広告主(メーカー・ショップ)の表示とされうる(運用基準 第2の1(2)ア(ウ)) | 広告主が違反を問われないよう、また**ASPの規約上の義務として**、広告であることを明瞭にする。表示が無いと提携解除・報酬の没収になりうる |
| B. 自社の商品の売り手 | SUZURIのグッズを記事・SNS・メルマガで紹介 | YAMATO OUTDOOR自身の表示(規制の当事者) | 自社のサイト・自社アカウントでの表示は「事業者の表示であることが明らか」(運用基準 第3の2(2)オ・カ)。ただし**第三者の感想に見せる形**(社外の人に頼んだ感想・自作のレビュー)は不可 |
| C. 媒体としての取材記事 | メーカーの協力を得た取材・貸与品のレビュー | 自主的な企画・編集なら事業者の表示にならない(運用基準 第2の2(2))。**通常の範囲を超える金銭・謝礼・内容への関与**があれば広告主の表示になる | 編集の独立を契約・メールで守る(2章)。提供・貸与の事実は、規制の要否にかかわらず読者に明示する(社内基準) |

### 1-2. 表示のルール(社内基準)

| 場面 | 必須の表示 | 置き場所 | 根拠 |
|---|---|---|---|
| ASPのリンクを1本でも含む記事 | `<p class="pr-notice">※ 本記事にはアフィリエイトリンクを含みます。報酬の有無で評価は変えていません。</p>` | 本文の冒頭(リードより前)。末尾だけは不可 | 運用基準 第3の1(2)オ(末尾は視認しにくい)・ASP規約 |
| メーカーから貸与・提供を受けた装備のレビュー | pr-notice に加えて「この記事の◯◯は、△△から貸与(提供)を受けて使用した。記事の内容について事前の確認は受けていない」 | 冒頭のpr-noticeの直後 | 運用基準 第3の2(1)イ(「A社から商品の提供を受けて」型の文章表示)|
| 対価を受け取る記事(タイアップ) | 冒頭に「PR」と「広告主名」。タイトルか冒頭1行目に入れる | 冒頭。文字を小さく・薄くしない | 運用基準 第3の2(1)ア・第3の1(2)カ/キ |
| 自社グッズの紹介 | 「YAMATO OUTDOORのグッズ(自社商品)」と分かる書き方 | その段落の中 | 運用基準 第3の2(2)オ |
| SNS投稿(ASPリンク・提供品・自社商品) | 冒頭に「PR」または「広告」。ハッシュタグの山に埋めない | 投稿文の1行目 | 運用基準 第3の1(2)ク |
| メルマガ・LINE(ASPリンクを含む) | 本文の冒頭に「このメールには広告(アフィリエイトリンク)を含みます」 | 冒頭 | 同上+ASP規約 |
| 動画 | 冒頭に表示し、十分な時間出す | 冒頭(中間・末尾だけは不可) | 運用基準 第3の1(2)ウ |

使わない書き方(不明瞭とされる例・運用基準 第3の1(2)):「広告」と書いた後に「個人的な感想です」と打ち消す / 「Sponsored」だけ(一般の読者に分かりにくい文言)/ 周りより小さい・薄い文字 / 長文の中に紛れ込ませる。

### 1-3. 表示の中身(優良誤認・有利誤認・規約)

| 論点 | ルール | 根拠 |
|---|---|---|
| 価格 | 税込と**確認日**を書く。セール価格は終了日を書くか、終わったら消す | 景品表示法5条2号(有利誤認)・Amazonポリシー(終了したプロモーションの記載は直ちに削除) |
| Amazonの価格・在庫 | 本文に手で価格を書かない(Amazonが提供するリンクのデータかCreators API経由のときだけ表示可)。比較表の「参考価格」はメーカー希望小売価格を出典つきで | Amazonプログラム・ポリシー |
| 性能の言い切り | 実測していない性能を断定しない(「防水」「最軽量」など)。メーカー値はメーカー値と書く | 5条1号(優良誤認)・`docs/content-pipeline/rules.md` R1 |
| No.1・最安・最軽量 | 調査の範囲・時点・出典が書けないものは使わない | 5条1号 |
| 短縮リンク | Amazonへのリンクを、Amazonだと分からない短縮URLで隠さない | Amazonプログラム・ポリシー |
| メール・SNSのDMでのAmazonリンク | オプトインした相手への配信だけ可。印刷物(チラシ・イベント配布物)には使わない | Amazonプログラム・ポリシー |

## 2. 提供・タイアップの契約の論点(PR部・コンテンツ部から相談を受けたとき)

契約書・発注書の確認は**専門家へ**。法務はPR部の提案書・条件メモに、次の論点が入っているかを見て、欠けを返す。

| 論点 | YAMATO OUTDOORの標準 | 外れたら |
|---|---|---|
| 編集の独立 | 先方の事前確認は**事実の誤り(仕様・価格・名称)の指摘だけ**。評価・構成・合わなかった点は変えない | 先方が評価・表現を直せる条件なら、記事全体を「広告」として扱い、冒頭にPRと広告主名(1-2) |
| 掲載の約束 | 貸与・提供だけでは掲載を約束しない(使って合わなければ書かない・合わなかった点も書く) | 掲載を約束する=対価性が強まる。PR表記を前提にCEO判断 |
| 合わなかった点 | 書く(Editorial Policy 3)。削除の要求は受けない | 受けるならその記事は出さない |
| 写真・ロゴの使用 | 先方の画像を使うなら、使用範囲(記事・SNS・期間)を書面(メール可)で許諾 | 許諾が無い画像は使わない(3章) |
| 対価 | 金額・物品・招待(きょう応)はすべて対価(運用基準 第2の1(2)イ 注)。受け取ったら全部表記 | — |
| 二次利用 | 先方がYAMATO OUTDOORの記事・写真を広告に使うときは、範囲と期間を決める | 決めずに使わせない |
| 競合排他 | 受けない(比較記事が書けなくなる) | CEO判断 |
| 記事の修正・削除 | 事実の誤りは直す。それ以外は編集部の判断 | — |

## 3. 著作権・画像の権利

| 素材 | 使ってよいか | 条件 |
|---|---|---|
| 運営者・メンバーが撮った写真 | 可 | 人が写っていれば本人の同意(顔が分かるもの)。登山者の顔は原則ぼかすか、写らない構図 |
| メーカーの製品画像 | 許諾があるときだけ | プレス素材の利用規約か、メールでの許諾を記録(誰が・いつ・範囲)。「公式サイトに載っているから」は理由にならない |
| 他サイト・SNSの写真 | 原則使わない | 引用(著作権法32条)は、①公表済み ②引用の必然性 ③本文が主で引用が従 ④括弧・blockquoteで区別 ⑤出所の明示(48条)を全部満たすとき。写真を「雰囲気づくり」に使うのは引用にならない |
| 地図(地理院地図など) | 出典の表記ルールに従う | 使う前にその地図の利用規約を確認し、`sources.md` に行を足す |
| AIで生成した画像 | 可(社内基準で表示) | 実在の製品・場所の「写真」に見えるものは作らない(実測・体験の誤認になる)。図解・イメージは可 |
| フリー素材 | ライセンスを記録できるものだけ | 出どころURL・ライセンス名・確認日をクリエイティブ部の記録に残す |

出どころが分からない画像は「使わない」が既定。判断を求められたら、出どころ・許諾の記録・引用の要件のどれが欠けているかを返す。

## 4. 商標

| 場面 | 手順 | 判断 |
|---|---|---|
| グッズの商品名・ロゴ(グッズ部から依頼) | J-PlatPatの「商標検索」で、称呼(読み)と文字で検索。区分は商品に合わせる(衣類=25類、かばん=18類、食器・ボトル=21類、紙製品・ステッカー=16類 など。区分の最終判断は弁理士) | 同一・類似の称呼で同じ区分に登録・出願があれば「類似の登録あり。名称変更を推奨」。無くても「出願するか」はCEO判断(費用が要る=L2) |
| 媒体名「YAMATO OUTDOOR」 | 年1回、上と同じ検索をする(情報提供・電子出版物は41類、広告は35類が目安) | 第三者の出願を見つけたら、すぐCEOへ(異議申立てには期限がある。専門家へ) |
| 記事中の他社の商標 | 「ゴアテックス」などの商標は、その商標の製品を指すときだけ使う(`docs/tone-and-manner.md` 2-4) | 一般名詞として使わない |

結果は「検索日・検索語・区分・ヒット件数・類似と見た登録の番号」を記録する(画面のスクリーンショットは非公開リポジトリへ)。

## 5. 個人情報(LINE・メール・問い合わせ・イベント)

立ち上げ時点の前提:**いまは個人情報を集める受け口が無い**(`src/lib/site.ts` の `CONTACT_URL` `NEWSLETTER_URL` `LINE_FRIEND_URL` が空)。
受け口を開ける前に、次がそろっていること(コミュニティ部の開設提案を法務が確認する)。

| 項目 | ルール | 根拠 |
|---|---|---|
| 利用目的 | 集める画面に、目的を具体的に書く(「更新のお知らせと、関西の山の情報を月1〜2回送るため」)。目的外に使わない | 個人情報保護法17・18・21条 |
| /privacy の改定 | いまの /privacy は「氏名・住所・電話番号などを直接お預かりすることはありません」と書いている。**受け口を開ける前に、取得する情報(メールアドレス等)・目的・委託先を書く改定が必要**(サイト開発部が実装) | 同21条 |
| 委託先(外国) | Googleフォーム・MailerLite・LINEなど、どの事業者のどの国のサーバーに置くかを記録。外国の事業者に置くときは、その国の制度を把握して安全管理措置に書く | ガイドライン通則編 10-7(外的環境の把握)・28条 |
| 安全管理 | 一覧のダウンロードはCEOだけ。AIが扱うのは件数と、個人を特定しない形に直した質問の中身だけ。公開リポジトリ・Notionの共有ページに個人情報を書かない | 23条・ガイドライン10 |
| 漏えい | 送信先の誤り・共有設定の誤りに気づいたら、その場でCEOへ。報告の要否は専門家へ | 26条 |
| 開示・削除の請求 | 受け付けたらCEOへ。AIは返信の下書きまで | 33条以下 |
| 写真(イベント) | 撮影・掲載の可否を申込時に聞く。顔が分かる写真は本人の同意が無ければ載せない | 社内基準 |

## 6. メール配信(特定電子メール法)

メルマガは原則「広告宣伝メール」に当たる前提で扱う(総務省パンフレット)。

| 項目 | ルール |
|---|---|
| 同意 | 登録フォームで本人が入力したアドレスにだけ送る(オプトイン)。チェックボックスをあらかじめ入れておかない。名刺・問い合わせで知ったアドレスを勝手に登録しない |
| 同意の記録 | 登録日時・方法・そのとき表示していた文言を保存(最後に送った日から1か月以上。社内では配信を続ける間ずっと) |
| 表示 | 毎号に、送信者の名称(YAMATO OUTDOOR と運営者)・配信停止の方法(URLかアドレス)・送信者の住所・苦情や問い合わせの受付先。**住所の出し方(個人の自宅住所を避ける方法)はCEOが専門家に確認してから開設する** |
| 停止 | 停止の申し出を受けたら、以後は送らない。停止の記録も残す |
| Amazonリンク | オプトインした相手にだけ可(1-3) |

## 7. 外部送信(電気通信事業法 27条の12)

| 項目 | YAMATO OUTDOORの整理 |
|---|---|
| 対象か | 「ホームページの運営[ニュースサイト、まとめサイト等各種情報のオンライン提供]」に当たる前提で、公表で対応している(総務省の対象一覧)。個人ブログ扱いで対象外とする判断はしない |
| 公表の中身 | 送信される情報の内容・送信先の事業者名・利用目的(+オプトアウトの手段があれば)。`src/lib/analytics.ts` の `measurementTransmissions()` が /privacy の表を作る |
| 公表の場所 | 外部送信をするページか、そこから容易に到達できるページ。→ 全ページのフッターから /privacy にリンク(監査のD) |
| 載せないもの | Cloudflare(配信)・Google Fonts・microCMSの画像配信=表示のために必要な通信と整理(適用除外)。**ただし計測が目的の送信は、事業者が配信と同じでも載せる**(例:Cloudflare Web Analytics のビーコン) |
| ずれの直し方 | 法務が検知・判断 → サイト開発部が `analytics.ts` に行を足す(またはタグを止める)→ CEOがmainへのマージを承認(ORG.md 3章) |

## 8. イベント・企画登山(コミュニティ部から相談を受けたとき)

| 論点 | ルール |
|---|---|
| 旅行業法 | 参加費を集めて、交通(バス・相乗りの手配)や宿泊を組み込むと旅行業に当たる可能性がある(実費・赤字でも)。**既定は「現地集合・現地解散・交通と宿泊は各自・参加費なし」**。参加費や送迎が要る企画は、所管(都道府県の旅行業担当)か専門家に確認してから |
| 安全・責任 | 中止基準(天候・人数)・エスケープルート・連絡体制・参加条件を企画書に書く。保険(主催者の賠償責任・参加者の傷害)の要否はCEOが確認 |
| 免責の書き方 | 「一切責任を負いません」とは書かない(消費者契約法で無効になりうる論点。専門家へ)。危険の説明と参加条件で対応する |
| 個人情報 | 5章のとおり。緊急連絡先・健康状態は要配慮・機微な情報になりうるので、集める項目を最小にする |
| 告知 | 告知はL2(CEO承認)。ASPリンク・自社グッズを含めるなら1-2の表示 |
