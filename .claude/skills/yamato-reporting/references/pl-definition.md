# P&Lの定義(科目・計上の基準・按分)—— 事業報告部

この部のP&Lは**管理会計**(事業の判断と実績の説明のため)であって、税務申告の帳簿ではない。
税務の扱い(科目の確定・減価償却・家事按分の可否・物品の受領の扱い)は、**事業の形(個人事業か会社か)と申告の方法をCEOに確認したうえで、CEOが税理士に確かめる**。
確認が済むまで、台帳の「税務の科目」は「候補」として扱う。

> **CEOに確認すること(未確認のまま進めない項目)**
> 1. 事業の形:個人事業(開業届の有無・青色か白色か)/ 会社 / まだ決めていない(副業の雑所得として扱っている など)
> 2. 会計期間:1〜12月(個人事業)/ 会社の事業年度
> 3. 会計ソフトの有無(あれば、台帳はソフトへの転記の下ごしらえになる)
> 4. 兼用の物(PC・スマホ・通信・車・登山の装備)の事業割合と、その根拠にするもの(作業時間の比率・走行距離 など)
>
> 答えをもらったら、この欄の下に「YYYY-MM-DD CEO確認:…」と書き足す(金額は書かない)。

---

## 1. 科目(管理会計)

| 区分 | 科目 | 中身 | 税務の科目(候補) |
|---|---|---|---|
| 売上 | アフィリエイト | ASPの**確定額**(発生ではない) | 売上(雑収入の可能性もある。CEO確認) |
| 売上 | グッズ(SUZURI) | **トリブン(作り手の利益)だけ**。販売価格の総額を売上にしない(販売価格=アイテムの原価+トリブン) | 売上 |
| 売上 | その他 | 原稿料・タイアップ(発生したら) | 売上 |
| 費用 | サイトの運営 | ドメイン・配信(Cloudflare)・microCMS・メール配信・フォーム | 通信費 / 支払手数料 |
| 費用 | ツール | AI(Claude など)・デザイン・分析ツールのサブスクリプション | 通信費 / 支払手数料 |
| 費用 | 取材の交通 | 登山口までの高速・ガソリン・駐車場・電車・バス | 旅費交通費 |
| 費用 | 検証用の装備 | 記事で量る・使うために買った道具 | 消耗品費(10万円以上なら減価償却の可能性。CEO・税理士) |
| 費用 | 撮影機材 | カメラ・レンズ・スケール(重量計)・三脚 | 消耗品費 / 減価償却費 |
| 費用 | 資料 | 地図・書籍・有料の山の情報 | 新聞図書費 |
| 費用 | 外注 | 人に頼んだ作業(撮影・デザインなど) | 外注費 |
| 費用 | 広告 | 有料の広告(使ったら) | 広告宣伝費 |
| 費用 | 手数料 | 振込手数料・決済手数料 | 支払手数料 |
| 費用 | その他 | 上のどれにも当たらないもの。**月に3件を超えたら科目を足す案を出す** | 雑費 |

科目を足す・変えるときは、前月までの行をどう扱うか(遡って付け替えるか)を決めてから。勝手に付け替えない。

## 2. 計上の基準(いつの月に載せるか)

| 取引 | 計上月 | 理由 |
|---|---|---|
| アフィリエイト | **確定した月**(ASPの「確定」の日)。発生・確定・入金は3列で別に持ち、P&Lは確定ベース | 発生はキャンセル・否認で減る。入金は2〜3か月遅れる |
| SUZURI | トリブンが確定した月(SUZURIの管理画面の表示に合わせる。CEOが確かめた値) | |
| 費用(都度払い) | 利用した月。利用日が分からなければ支払日 | |
| 費用(年額払い) | **12か月に月割り**(1か月分ずつ)。支払った月に全額を載せない | 1か月だけ赤字が膨らみ、時間あたり利益の推移が読めなくなる |
| 費用(10万円以上の機材) | 管理会計では**36か月で月割り**(社内の初期値)。税務の扱いは別(CEO・税理士) | 同上 |
| 物品の受領(PR部のサンプル提供) | 受領の記録だけを付ける(金額は「未確認」)。売上・費用には入れない | 税務の扱いが決まっていないため。CEO確認 |

## 3. 按分(私用と兼用のもの)

- 既定は100%(事業だけに使うもの)。兼用のものだけ、**事業割合と根拠**を台帳に書く
- 割合の根拠の例:PC・通信=作業時間の比率 / 車=走行距離の比率(取材の往復 ÷ 月の走行距離)/ 登山の装備=記事で量ったかどうか(量った装備だけ検証用)
- 割合はCEOが決める。AIは根拠の数字(作業時間ログの合計など)をそろえて案を出すだけ
- 一度決めた割合は、根拠が変わらない限り月ごとに変えない(変えたら理由を残す)
- 登山の扱い:目的に「取材(記事)」「実測」が入っている登山は交通費を事業に、私用だけの登山は入れない。取材と私用を兼ねた日の割合はCEOが決める

## 4. 指標と、理由を書く線

| 指標 | 式 | 見方 |
|---|---|---|
| 売上 | アフィリエイト(確定)+ SUZURI(トリブン)+ その他 | 分析部の確定値を写す。集計し直さない |
| 費用 | 計上額(事業割合を掛けた額)の合計 | |
| 営業利益 | 売上 − 費用 | 立ち上げ期はマイナスが普通。マイナスを隠さない |
| 営業利益率 | 営業利益 ÷ 売上 | 売上が0の月は出さない |
| 時間あたり利益 | 営業利益 ÷ 作業時間(CEO) | 作業時間が空の月は出さない(0で割らない・推定しない) |
| 累計 | 事業を始めた月からの営業利益の合計 | 「月◯万円の利益を出した」と言えるかの根拠 |

計画との差に理由を書く線(社内の初期値):**計画比±20%以上、かつ金額で±5,000円以上**ずれた科目。理由は各部の報告から引用し、自分で作らない。
引用できる報告が無ければ「理由は未確認(<部>に確認を依頼)」と書く。

## 5. 証憑(領収書)の扱い

- 費用の行には、領収書の有無(あり紙 / あり電子 / なし / 回収待ち)を必ず付ける
- **メール・PDF・Webの画面で受け取った領収書は、電子のまま保存する**(紙に印刷して捨てない。国税庁「電子帳簿保存法関係」https://www.nta.go.jp/law/joho-zeikaishaku/sonota/jirei/index.htm 2026-11-01確認。保存の要件の詳細はCEO・税理士)
- 保存期間は申告の方法で5〜7年(国税庁タックスアンサー No.2080 ほか。2026-11-01確認)。どれに当たるかはCEOに確認
- 「なし」の費用は、月次の報告書で件数と金額の合計を出す(放置しない)
