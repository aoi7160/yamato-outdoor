# Notionの台帳の設計(事業報告部)

置き場所:Notion「YAMATO BASE CAMP」の下。**実データ(金額・時間・写真)はNotionにだけ置き、公開リポジトリには書かない**(STANDARDS 5章)。
スキルの実行時に、Notionを検索して下の4つのデータベースがあるかを確かめ、**無いものだけ**この設計で作る(L1)。
作ったら、日報の自分の節に「<DB名>を作成」と1行書く。データベースのIDやURLは公開リポジトリに書かない。

既存のデータベースが、この設計と違う項目で作られていたら、作り直さずに**足りない項目だけ足す**(CEOがすでに入れた行を壊さない)。
項目名を変えたいときは、変える前にCEOに聞く(コンソールや他部が項目名で読んでいる可能性がある)。

---

## 1. P&L台帳(取引の明細。1行=1取引)

| 項目 | 種類 | 選択肢・書き方 | 必須 |
|---|---|---|---|
| 内容 | タイトル | 「Xserverドメイン 年額」「六甲 取材 高速代」など。誰が見ても何の取引か分かる | ○ |
| 日付 | 日付 | 取引日(売上は確定日、費用は支払日または利用日。`pl-definition.md` 2章) | ○ |
| 計上月 | セレクト | `YYYY-MM`。年額の月割りは、月ごとの行を作るか、計上月を「按分表」側で持つ(`pl-definition.md` 3章) | ○ |
| 区分 | セレクト | 売上 / 費用 | ○ |
| 科目 | セレクト | `pl-definition.md` 1章の管理会計の科目 | ○ |
| 税務の科目(候補) | セレクト | 通信費 / 旅費交通費 / 消耗品費 / 新聞図書費 / 支払手数料 / 広告宣伝費 / 外注費 / 減価償却費 / 雑費 など。**事業の形(個人事業か会社か)が決まるまで「候補」**。確定はCEO・税理士 | |
| 金額(税込) | 数値(円) | 税込で入れる。売上は確定額 | ○ |
| 事業割合 | 数値(%) | 100が既定。私用と兼用のものだけ下げる。根拠は「按分の根拠」に | ○ |
| 計上額 | 数式 | `金額(税込) × 事業割合 / 100`(四捨五入しない。合計で丸める) | ○ |
| 按分の根拠 | テキスト | 「作業時間の比率(10月 32時間/月の利用 64時間)」など。CEOの確認日 | 兼用のとき○ |
| 支払方法 | セレクト | クレジットカード / 口座振替 / 現金 / ASPからの入金 / SUZURIからの振込 / その他 | |
| 領収書 | セレクト | あり(紙)/ あり(電子)/ なし / 回収待ち | 費用のとき○ |
| 領収書ファイル | ファイル | 紙はスキャン、電子は受け取ったPDF・メールのまま(電子取引のデータは電子のまま保存。`pl-definition.md` 5章) | |
| 出どころ | テキスト | 売上:「データ分析部の確定値(11/1の日報)」/ 費用:「CEOの入力(11/3)」など | ○ |
| 部 | セレクト | 費用を使った部・目的(記事・取材・アプリ・SNS・営業・計画と報告・グッズ・共通) | |
| 状態 | セレクト | 下書き / 確定 / 修正済み | ○ |
| 修正履歴 | テキスト | 確定後に直したら「YYYY-MM-DD 何を・なぜ・誰の承認」 | |

ビュー:今月(計上月=今月)/ 回収待ち(領収書=回収待ち)/ 売上(区分=売上・発生確定入金の確認用)/ 未分類(科目が空)。

## 2. 作業時間ログ(1行=1日×1区分)

| 項目 | 種類 | 選択肢・書き方 | 必須 |
|---|---|---|---|
| 内容 | タイトル | 「六甲 取材(手袋の実測)」「承認トレイのレビュー」など | ○ |
| 日付 | 日付 | 作業した日 | ○ |
| 区分 | セレクト | 記事 / 取材 / アプリ / SNS / 営業 / 計画と報告 / その他 | ○ |
| 時間 | 数値(時間・小数1桁) | 0.5単位 | ○ |
| 誰 | セレクト | CEO / メンバー(名前は書かず役割)。**AIの作業時間は入れない**(AIの費用は台帳の費用) | ○ |
| 登山 | リレーション | 登山記録へ(取材の行のとき) | |
| 出どころ | テキスト | 「CEOの自己申告(日報 11/3)」など | ○ |

時間は**CEOの申告だけ**を記帳する。AIが推定して埋めない。申告が無い日は空のまま(0とも書かない)。

## 3. 登山記録(1行=1回の登山)

| 項目 | 種類 | 選択肢・書き方 | 必須 |
|---|---|---|---|
| 山名 | タイトル | 正式名称(「六甲山(最高峰)」など) | ○ |
| 日付 | 日付 | | ○ |
| 山域 | セレクト | 六甲 / 金剛・葛城 / 比良 / 大峰 / 岩湧山 / 北摂 / 京都北山 / アルプス / その他 | ○ |
| 標高(m) | 数値 | 出典(国土地理院など)を「メモ」に | |
| ルート | テキスト | 登山口〜下山口。コースタイム(出典)と実際の時間 | |
| 人数 | 数値 | | |
| 天気 | テキスト | 実際に記録した値(気温・風)。写真から読み取ったものは「推測」と書く | |
| 目的 | マルチセレクト | 取材(記事) / 実測 / 撮影 / 私用 / イベント | ○ |
| 関係する記事 | テキスト | 記事のURLか、承認トレイの件名 | |
| 写真 | ファイル | **リポジトリに入れない**(顔が写る)。ここにだけ置く | |
| 確認 | セレクト | 推測あり(CEO確認待ち)/ CEO確認済み | ○ |
| メモ | テキスト | 事実だけ。感想は書かない | |

## 4. 月次の締め(1行=1か月)

| 項目 | 種類 | 書き方 | 必須 |
|---|---|---|---|
| 月 | タイトル | `YYYY-MM` | ○ |
| 状態 | セレクト | 回収中 / 下書き / CEO確認待ち / 確定 / 修正済み | ○ |
| 売上(確定ベース) | 数値 | 台帳の合計(区分=売上・計上月=この月) | ○ |
| 費用 | 数値 | 台帳の計上額の合計 | ○ |
| 営業利益 | 数式 | 売上 − 費用 | ○ |
| 作業時間 | 数値 | 作業時間ログの合計(CEO) | ○ |
| 時間あたり利益 | 数式 | 営業利益 ÷ 作業時間(作業時間が0か空なら空) | ○ |
| 計画との差 | テキスト | 計画がある科目だけ。`pl-definition.md` 4章の線を超えたものに理由 | |
| 未回収 | 数値 | 領収書=回収待ちの件数 | ○ |
| 確定日 | 日付 | CEOが確定にした日 | |
| 報告書 | URL | 月次事業報告書(社内版)のページ | |

この行の数字は、台帳とログから**検算して一致したときだけ**書く(`formats.md` 4章のチェックリスト)。
