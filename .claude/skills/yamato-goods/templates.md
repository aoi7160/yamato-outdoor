# グッズ部の出力テンプレート(実例つき)

例の企画・価格は**書き方の説明用**。原価・トリブンの数字は、使うときにSUZURIの画面で確かめた値に置き換える。

## 1. 企画書(`content/goods/<YYYY-MM>-<slug>/concept.md`)

```markdown
# 企画:比良の稜線ステッカー(2026-12 / hira-ridge-sticker)

- 起案:2026-11-02 グッズ部(企画AI) / 状態:法務確認待ち
- 依頼元:自主企画(企画部の需要カレンダー:12月 年末年始・来年の山)

## 誰の、どの場面か
P1。比良の武奈ヶ岳に向かう朝、車のダッシュボードの横に置いたボトルに貼ってある。
山頂でボトルを出したとき、同行者の目に「YAMATO OUTDOOR」が入る。

## 企画採点表(11点以上で案出し)
| 項目 | 点 | 根拠 |
|---|---|---|
| ① 山で使う場面 | 3 | ボトル・ヘルメットに貼って山へ持っていく |
| ② ペルソナ | 3 | P1の比良の日帰りの場面が書ける |
| ③ 名前と世界観 | 3 | YAMATO OUTDOOR+ダークトーンのシルエット |
| ④ 関西・Mission | 3 | 実在の比良の稜線(国土地理院の断面図から起こす) |
| ⑤ SUZURIの品質 | 2 | 1色の線と面。細い等高線は潰れるので入れない |
| 合計 | 14 | |

## 図案の題材と出典
- 稜線:比良山地の主稜線の断面(地理院地図の断面図で区間を指定。標高の数字は図案に入れる前に地理院地図で確かめる)
- 句:「次の一歩は、ここから。」(Missionの語彙「一歩」)

## 案
- A:稜線を横いっぱいに、下に YAMATO OUTDOOR(draft-a.svg)—— 名前を強く
- B:丸の中に稜線、外周に YAMATO OUTDOOR と山名(draft-b.svg)—— 山名を強く

## 価格(承認依頼の前に画面で確かめる)
- 原価:◯◯円(YYYY-MM-DD確認・アイテム作成画面)/ トリブン:100円(名刺の帯)/ 販売価格:◯◯円
- 振込手数料を引いた手残りの見込み:月◯枚売れて◯◯円(推測)

## 確認依頼
- 法務部:語「YAMATO OUTDOOR」「比良」・図案(稜線)/ 候補の区分 第16類 / 稜線データの利用条件
- クリエイティブ部:法務の判断が出たらA・Bのうち採用案を清書(入稿サイズはアイテム作成画面の指定)
```

## 2. SVGのラフのひな形(`draft-a.svg`)

実寸(mm)の `viewBox` で作り、読めるかを確かめる。稜線の点列は、国土地理院の断面図から読み取った形に置き換える
(下の点列は**形の例**で、実在の稜線ではない)。**等間隔の三角形にしない**:頂の間隔と高さを不規則にする。

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 80 50" width="80mm" height="50mm">
  <!-- ラフ。入稿用のアウトライン化と色の確定はクリエイティブ制作部 -->
  <rect width="80" height="50" rx="3" fill="#14171a"/>
  <!-- 稜線:国土地理院の断面図(区間:◯◯〜◯◯)から起こした形に置き換える -->
  <path d="M4 34 L11 29 L15 31 L22 22 L26 25 L31 19 L38 24 L44 21 L52 27 L57 25 L63 30 L70 28 L76 33 L76 38 L4 38 Z"
        fill="#e8e4dc"/>
  <!-- 霧:単色の帯。グラデーションに頼らない(印刷で潰れる) -->
  <rect x="4" y="38" width="72" height="1.2" fill="#e8e4dc" opacity="0.5"/>
  <text x="40" y="46" text-anchor="middle" fill="#e8e4dc"
        font-family="Schibsted Grotesk, sans-serif" font-size="5" letter-spacing="1.2">YAMATO OUTDOOR</text>
</svg>
```

確かめること:`font-size="5"`(5mm)で名前が読めるか / 生地が白のとき用の反転版(`fill` の入れ替え)/ 1〜2色に収まっているか。

## 3. 承認トレイ「グッズ登録」

| プロパティ | 例 |
|---|---|
| 件名 | SUZURIに「比良の稜線ステッカー」を登録 |
| 状態 | 承認待ち |
| 依頼元 | goods |
| 種類 | グッズ登録 |
| 根拠 | 企画採点表14点 / 法務部:商標の判断 問題なし(YYYY-MM-DD)/ 清書:クリエイティブ部(画像URL)/ 原価◯◯円(YYYY-MM-DD確認)+トリブン100円 / 販売中のアイテム N点 → N+1点(上限10点の内) |
| 承認すると | CEOがSUZURIでアイテムを作成し、価格を設定して公開 → グッズ部がSNS部・コミュニティ部に告知の依頼を出す |
| 要約 | ボトルやヘルメットに貼られて山で名前が目に入る、名刺の役割のステッカー。比良の実在の稜線を図案にした |

本文の json(1つだけ):

```json
{
  "changes": [
    "SUZURIにステッカーを1点追加(案A)",
    "販売価格:◯◯円(原価◯◯円+トリブン100円・YYYY-MM-DD確認)"
  ],
  "images": [
    { "src": "https://(クリエイティブ部の清書の画像URL)", "alt": "比良の稜線とYAMATO OUTDOORの文字のステッカー案A", "caption": "案A(採用)" },
    { "src": "https://(案Bの画像URL)", "alt": "丸の中に比良の稜線を置いたステッカー案B", "caption": "案B(比較用)" }
  ],
  "links": [{ "label": "ショップ", "href": "https://suzuri.jp/yamato-outdoor/products" }]
}
```

画像のURLが無い(清書がまだ)なら、積まない。
