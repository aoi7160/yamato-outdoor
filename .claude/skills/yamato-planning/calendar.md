# 需要カレンダー(企画・編集会議部)

需要の山の正は2つある:コード上の `console/src/scripts/demo.ts` の `PEAKS`(コンソールの残り日数と警告に使う)と、
Googleカレンダー「YAMATO BASE CAMP」(運用の予定)。**このファイルは、その2つを逆算した作業用の表**。
`PEAKS` を変えたいときは、変更案をサイト開発部への依頼として出す(企画部はコードを変えない)。

## 3. 関西の山の暦(企画の時期とファクト確認の入口)

企画の時期の目安。記事に日付を書くときは、その年の公式の発表で確かめる(校閲部の事実確認の対象)。

| 時期 | 出来事 | 確度 | 出典(確認日 2026-11-01) |
|---|---|---|---|
| 毎年5月3日 / 9月下旬 | 大峰山(山上ヶ岳)大峯山寺の戸開式 / 戸閉式。戸開式の5月3日は情報が一致。戸閉式は9月23日とする資料(奈良県の広報誌)と9月26日とする記事があり食い違う。山上ヶ岳は女人禁制が続いている | 戸開は例年の日付 / 戸閉は要確認 | https://www.pref.nara.jp/secure/299358/kenmin07.pdf 、https://tabi-mag.jp/day0503/ |
| 12月末〜2月(1月下旬〜2月に出やすい) | 金剛山の霧氷・樹氷。寒波と気温次第で出ない年・日がある | 目安(登山記録からの傾向) | https://www.minnacamera.com/spots/2257 ほか登山記録(YAMAP) |
| 3月1日前後 | 渓流解禁(関西の多くの漁協。漁協ごとに異なる) | 未確認(釣りジャンルを開くときに漁協ごとに確認) | — |

足すときは、確度と出典URL・確認日を必ず書く。確認できないものは「未確認」と書き、日付を記事の根拠にしない。
