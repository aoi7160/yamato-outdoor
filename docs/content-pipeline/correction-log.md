# 運営者の修正記録(correction-log)

AIの下書きを運営者が直した箇所の記録。**次の記事で同じ指摘を繰り返さないため**に残す。

- 記事を公開したら `/article-learn <スラッグ>` で、最終下書きと公開版の差分からこの表に追記する
- 「一般化したルール」が埋まった行は、`style-guide.md` 10 または `docs/tone-and-manner.md` に
  反映し、「反映済み」に反映先を書く
- 1回きりの好み(その記事だけの言い回し)は、一般化せず「記事固有」とする
- **運営者が記入した実体験の中身はここに書かない**(公開リポジトリのため)。
  ここに残すのは「AIが何を書き、どう直されたか」という書き方の記録だけ

種別: `表現` / `構成` / `事実` / `体験の境界` / `装飾` / `メタ`(タイトル・概要・タグ)
