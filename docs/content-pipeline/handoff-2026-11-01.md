## 2. 要判断:1x1計測画像の自動除去が、ASPの規約の「改変」に当たるおそれ

- **もしも**:FAQで「HTMLソースの一部を変更」は「許可されておりません」。規約の禁止事項に「広告素材、広告リンク等を…許可なく改変すること」がある。出典:https://af.moshimo.com/af/www/help ・ https://af.moshimo.com/af/www/terms/shop
- **A8**:「テキスト広告の文言の変更、広告コードからリンク部分のみを使用すること」を改変として禁止している。出典:https://support.a8.net/a8/as/faq/2005/08/post_25.html ・ https://support.a8.net/a8/as/faq/2005/08/post_26.html
- このサイトの `src/lib/article.ts` は、ASPの1x1計測画像を自動で外している。`docs/workflow.md` の`buy-box`も、リンクのURLだけを使う書き方になっている
- 選択肢は次の3つ:
  - (a) 両ASPに「計測画像を外してよいか」問い合わせる
  - (b) 計測画像を残す。その場合は `src/lib/analytics.ts` の外部送信一覧に、A8・もしもを足す必要がある
  - (c) 計測画像の除去をやめ、`buy-box` もASPが出したコードをそのまま貼る形に変える
- **リンクを置き始める前に決める必要がある**(運営者の判断)

## 3. もしもアフィリエイトの手順(調査結果)

support.moshimo.com はこの環境のネットワーク許可に入っておらず、読めなかった。確認できたのは af.moshimo.com の公開ページだけ。

- **メディア登録が先に必要。** 「まずはサイトの登録を頂かないと、アフィリエイトを始めることはできません」。広告は登録したメディアにしか貼れない。
  入力項目は、旧画面の攻略本ではサイト名・URL・カテゴリ。今の画面の項目は未確認。
  出典:https://af.moshimo.com/af/www/guidebook3
- **提携の流れ。** プロモーションの詳細で「提携申請する」を押す。承認されると、ボタンが「広告リンク取得」に変わる。
  - 「審査なし」は即時、「審査あり」は5日〜2週間程度(攻略本)。FAQには「数か月の場合も」とある
  - 否認されても3日後から再申請できる
  - 出典:guidebook3 / help
- **3社の個別情報(未確認)。** 検索語・審査の有無・日数は未確認。Amazonの審査基準(記事数など)の公式な記載も見つからなかった。
  参考までに、A8のAmazonプログラムは「開設から日が浅い・コンテンツが少ない」サイトは申請を控えるよう書いている:https://support.a8.net/a8/as/faq/2017/post_1066.html
- **リンクの作り方**
  - 「どこでもリンク」:好きなURL(商品ページなど)へのテキストリンクを作れる。Amazonはテキストリンクのみ対応(2010年の発表で、今も同じかは未確認:https://www.moshimo.co.jp/news/release/detail?id=113)
  - 「かんたんリンク」:商品カード型のリンク。JSを含むかは未確認
  - 出典:https://af.moshimo.com/af/www/about/maf
- **口座は必須。** 未登録だと支払いが保留になる。保留分は、発生した年の翌々年12/31に失効する(規約9条)。
  インボイス番号は任意(番号か、免税事業者である旨の申告のどちらか)。出典:https://af.moshimo.com/af/www/terms/shop
- **本人申込(自己購入)。** 可否はプロモーションごとに決まっていて、詳細ページで確かめる。

## 4. A8.netの手順(調査結果)

- **提携申請の流れ。** プログラム検索 →「プログラム詳細を見る」→ アピールサイトを選ぶ →「プログラムの提携申請をする」。
  - 検索結果に「即時提携」か「審査あり」のアイコンが付く
  - 審査は即日〜数週間。45日承認されないと自動で取り消される
  - 結果は「申込中プログラム」「参加中プログラム」で確認できる
  - 出典:https://support.a8.net/a8/as/faq/manual/partnership.php ・ https://support.a8.net/a8/as/faq/2025/post_2602.html ・ https://support.a8.net/a8/as/faq/2014/08/as_2.html
- **任意の商品ページへのリンク。** 「商品リンク」アイコンがあるプログラムだけ作れる。
  作り方は、参加中プログラム →「商品リンク」→ リンク先URLとテキストを入れる → コードを生成。A8の素材はJSを使わない。
  出典:https://support.a8.net/a8/as/faq/2022/post_1885.html ・ https://support.a8.net/a8/as/faq/manual/how_to_post.php

## 6. 記事を書くときの注意(このセッションでの検討)

- 運営者は4社の実機を使っていない(確認したわけではない。記事にする前に取材シートで聞く)。
  実機の体験が無いなら、`rules.md` R1 により「使った」「量った」は書けない。
  書けるのは「公表値と計算から容量を選ぶ」記事。計算であって実測ではないことを本文に明記する
- 4社を1本の記事で比べるほうが、ブランドごとに体験の無い記事を4本書くより価値がある、と判断していた
- キャンプのカテゴリがまだmicroCMSに無い。genre `camp` のカテゴリを1つ作る必要がある(例:`gear`「キャンプ道具」。1本しか入らないカテゴリは作らない方針なので、名前は広めにする)

- 内部リンクに使える公開済みの記事は、サロモンの記事だけ(キャンプとは関係が薄い)
