# YAMATO OUTDOOR ペルソナ設計

メディアの読者像と、そこから逆算した「監修者に何を書くべきか」をまとめたもの。
記事の企画、タイトルの付け方、監修者プロフィールのコピーはすべてここを基準に判断する。

前提として、このメディアは2つの役割を持つ。

1. ロングテールSEOで検索流入を取る**情報メディア**
2. 自社アウトドアブランドの**信頼の受け皿**(買う前に「誰が作っているか」を確認される場所)

つまり読者は「答えを探しに来た人」であって、ブランドのファンではない。
ファンになるのは記事を読み終えたあとの話で、その転換点に監修者プロフィールが置かれている。

## メインペルソナ P1「失敗買いを二度したくない、働きながら月1で登る人」

流入の中心。記事の8割はこの人に向けて書く。

### ① デモグラフィック

| 項目 | 内容 |
|---|---|
| 氏名(仮) | 中村 亮太 |
| 年齢・性別 | 34歳・男性 |
| 居住地 | 大阪府吹田市(勤務先は梅田) |
| 学歴 | 私立大 経済学部卒 |
| 職業・役職 | IT系事業会社の営業企画。メンバー3名のリーダー |
| 年収 | 620万円 |
| 家族構成 | 既婚・子どもなし(共働き)。可処分所得はあるが「趣味に使いすぎ」と言われたくない |
| 移動手段 | 自家用車(登山口までは車、渋滞を避けて未明に出る) |

### ② ファーモグラフィック(BtoCなので「山行プロファイル」に読み替える)

| 項目 | 内容 |
|---|---|
| 登山歴 | 3年2ヶ月 |
| 頻度 | 月1〜2回。年間18日程度 |
| フィールド | 六甲・金剛・比良などの関西の日帰り低山が中心。年2〜3回、北アルプスや八ヶ岳へ遠征 |
| スタイル | 単独か、気心の知れた友人1〜2人。ツアーや山岳会には所属していない |
| 装備総額 | 約25〜30万円(ザック32L、レイン上下、3シーズンシューズ、テントは未所有) |
| 使用アプリ | YAMAP(無料プラン)、たまにヤマレコを検索で読む |
| 直近の買い物 | 冬用グローブ8,000円、行動食、ヘッドランプ |

### ③ サイコグラフィック

- **「失敗したくない」が最大の駆動力。** 過去2回、買って合わなかった道具がある(重すぎたザック、蒸れたレインウェア)。金額よりも「調べたのに外した」ことが悔しい。
- スペック表を読むのは好き。ただし**最後に決め手になるのは「実際に使い込んだ人の言葉」**。数値だけでは踏み切れない。
- 「山ガール」「映え」「#登山女子」的なノリには乗らない。**静かな山、朝の空気、無心で歩く時間**に価値を感じている。
- 意識高い系のブランド語りは冷める。一方で、**作り手のこだわりを淡々と語られるのには弱い**。
- 自分を上級者だとは思っていない。だが初心者向けの「まずは高尾山から」記事はもう卒業したと感じている。**この中間層向けの情報が一番少ないことに苛立っている。**
- SNSは基本「見る専」。投稿はしないが、良い記事はXでこっそりブックマークする。

### ④ ビヘイビア(行動特性)

- **検索クエリはロングテール。** 「六甲 全山縦走 コースタイム 初回」「レインウェア ゴアテックス 3万以下 比較」「ヘッドランプ 登山 200ルーメン 十分」のように、条件を3語以上重ねて検索する。
- **閲覧時間帯は平日22:30〜24:30のスマホ、休日午前のPC。** 平日の夜、寝る前に布団の中で比較記事を読む。
- 情報収集の順番:
  1. Google検索で比較記事を2〜4本読む(ここがYAMATO OUTDOORの接点)
  2. YouTubeで実機レビューを観る
  3. YAMAPの活動日記で「実際に使っている人」を確認する
  4. 価格.com・楽天・Amazonで最安を確認
  5. 好日山荘やmont-bell店頭で実物を見て、その場かセール時に買う
- **検討期間は2〜6週間。** 高額品(3万円以上)は必ずセール(1月・7月)まで待つ。
- 記事は**目次を見てから読む。** 全文は読まない。自分の条件に合う見出しだけを拾う。
- ブックマークはしない。**「また検索すれば出てくる」と思っているので、指名検索は起きにくい。**

### ⑤ ニーズ・課題(Pain)

- レビュー記事がアフィリエイト目的にしか見えず、**「悪い点」が書いていないので信用できない。**
- スペックの数字が、実際の山でどう効くのかが分からない(「耐水圧20,000mm」と言われても体感が想像できない)。
- **関西の山の情報が圧倒的に少ない。** 検索するとアルプスと関東の山ばかり出てくる。
- 平日は仕事で山に行けず、**月1の機会を天候と装備の失敗で潰したくない。**
- 単独行が多いので、安全面(道迷い・低体温症・エスケープ)に漠然とした不安がある。
- 体力に自信がない。年齢的にも、これ以上重い荷物は担ぎたくない。

### ⑥ ゴール(Goals)

- 短期: 次の遠征(9月の北アルプス)までに、レインウェアとヘッドランプを決着させたい。
- 中期: 「これで揃った」と言える装備一式を作り、買い物の悩みから解放されたい。
- 長期: 月1のペースを40代・50代になっても続けたい。いつかテント泊縦走をしたい。
- 感情的なゴール: **「ちゃんと調べて選んだ」という納得感。** 買った道具を人に説明できる状態。

### ⑦ 意思決定要因(Decision Factors)

購入・信頼の判断で見ているものを、重い順に並べる。

1. **同じ人が長期間使い続けているか**(単発レビューは信じない)
2. **悪かった点が具体的に書いてあるか**(欠点のないレビューは広告と判断される)
3. 実測値(カタログ重量ではなく、実際に量った重量)
4. 雨・寒さ・汗など、**悪条件での挙動**
5. 価格と、値引きのタイミング
6. 日本人の体型・体格に合うか(海外ブランドのフィット問題)
7. 修理・保証・サポート体制
8. 「誰が書いたか」——プロフィールに実体験が見えるか

## ペルソナから逆算する「監修者プロフィール」の要件

コピー本文は書き手(あなた)が書くとして、**何を証明すべきか**をここで固定しておく。

### 刺さる軸

1. **同じ制約を持っていること。**
   P1が最も反応するのは「プロの登山家」ではなく「働きながら月1で登り続けている人」。
   月1という頻度は弱点ではなく、**P1と同じ土俵に立っている証拠**として書く。
   「年間100日入山」の人の装備論は、P1にとっては自分ごとにならない。

2. **同じフィールドを歩いていること。**
   関西の山を軸にしていることは、関西在住のP1・S1に対して**最大の差別化**になる。
   「アルプスの記事しか出てこない」という不満に直接応える資産なので、必ず具体名を出す。

3. **検証の視点を持っていること。**
   「仕様と検証データから入ってしまう」という性質は、P1の④⑦(実測値・悪条件での挙動)に
   ぴったり重なる。**感想文ではなく検証記事である**という宣言として機能する。

4. **作り手であること。**
   S2に効く。同時に、P1に対しては「スペックの裏側を知っている人」という権威づけになる。
   ただし宣伝臭が出ると P1 は冷めるので、**ブランドの話は最後に一行**で足りる。

### プロフィールに入れるべき情報の型

- 登山を続けている**年数**と、**継続の頻度**(数字を1つ以上)
- **具体的な山名**(関西を軸にしていることが分かる固有名詞を3〜4)
- どういう山行をするか(日帰り／縦走／夜間など、記事のテーマと接続する)
- 検証のスタンスが分かる一文
- ブランドを立ち上げた事実(短く)

### 書かないほうがいいもの

- 資格や肩書きの匂わせ(「ガイド」等、実態と違う語は E-E-A-T 上もリスク)
- 「登山家」「アドベンチャー」など、P1が距離を感じる語
- 他ブランドの批判
- 盛った実績。P1は一貫性を見ているので、記事本文と食い違った瞬間に信頼が消える

## ペルソナが企画に与える制約(記事側のルール)

- **タイトルは条件を3つ以上含める。** 「レインウェアの選び方」ではなく
  「3万円以下・ゴアテックス・関西の低山で使うレインウェアの選び方」
- **必ず「合わなかった点」を書く。** これがない記事はP1にとって広告と同義
- **カタログ値ではなく実測値を書く。** 重量は自分で量った数字を載せる
- **関西の山を例に使う。** 六甲・金剛・比良・大峰は、それだけで検索とリアリティの両取りになる
- **目次で拾い読みできる構成にする。** P1は全文を読まない
- **記事の最後に「次に読むべき1本」を置く。** 指名検索が起きにくい層なので、回遊で滞在を作る
