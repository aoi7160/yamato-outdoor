# YAMATO OUTDOOR ブランド設計 / ペルソナ

このメディアとブランドの土台。記事の企画、コピー、プロフィール、製品の判断は
すべてここを基準にする。迷ったら Value に戻る。

---

## 0. Mission / Vision / Value

### Mission

> **挑戦の、ベースキャンプになる。**

ベースキャンプは、頂上に立つ場所ではない。そこから人が出ていくための場所であり、
荷を整え、天候を読み、次の一歩を決める場所。
物販でもメディアでも支援でも、やっていることの中身は変わらない。
挑む人が、そこから出ていける状態をつくる。

### Vision

> **終わりなき成長に、挑む輪を広げていく。**

到達点を決めた時点で、成長は止まる。
終わりがないから、人はどこまでも行ける。
誰が、いつ始めてもいい。
その輪を、社会に広げていく。

### Value

| | | |
|---|---|---|
| 01 | 名実一体 | 誰に聞いても一流と認められる自分たちでいる。 |
| 02 | 大胆自責 | 責任を取れる範囲が、挑戦の大きさを決める。 |
| 03 | 敢為邁往 | 分かれ道では、険しい方へ。楽に着いた場所に、見たい景色はない。 |
| 04 | 格物致知 | 誰かの地図を、そのまま歩かない。人が動く理由は、自分で読み解く。 |
| 05 | 好学不倦 | 考えるのをやめた瞬間、毎日はただの繰り返しになる。 |

Value は会社としての行動指針であって、記事の書き方の話ではない。
記事の約束事は「4. Editorial Policy」に置く。混ぜると両方が小さくなる。

## 1. YAMATO OUTDOOR の立ち位置

YAMATO OUTDOOR は、グループの Mission を最初に実装した事業。
アウトドアという領域を選んだのは、**挑戦と準備の関係が、そのまま目に見える**領域だから。

三階建てで動く。

| 階 | やること | 今 |
|---|---|---|
| 記録する | 使った装備と歩いたルートを記録するメディア | 稼働中 |
| 作る | 自分たちで使うための道具をつくる | 立ち上げ |
| 送り出す | 人が実際に山へ出ていく状態をつくる(場・仲間・企画) | 構想 |

読者は最初から仲間ではない。**答えを探しに来た人**として入ってくる。
記事はその人の準備を助け、結果として「次に行く日」が決まる。
そこが、このメディアがベースキャンプであるという意味。

## 2. メインペルソナ P1「山が生活のリズムになりかけている人」

流入と記事の中心。記事の8割はこの人に向けて書く。

**再定義のポイント:** 主語は「道具」ではなく「次に行く日」。
道具の失敗が悔しいのは金額ではなく、**1回分の休みを損したから**。
だからこのメディアの仕事は買い物の答え合わせではなく、次の一歩を軽くすること。

### デモグラフィック

| 項目 | 内容 |
|---|---|
| 氏名(仮) | 中村 亮太 |
| 年齢・性別 | 34歳・男性 |
| 居住地 | 大阪府吹田市(勤務先は梅田) |
| 職業 | IT系事業会社の営業企画。メンバー3名のリーダー |
| 年収 | 620万円 |
| 家族構成 | 既婚・子どもなし(共働き)。可処分所得はあるが「趣味に使いすぎ」と言われたくない |
| 移動手段 | 自家用車。渋滞を避けて未明に出る |

### 山行プロファイル

| 項目 | 内容 |
|---|---|
| 登山歴 | 3年2ヶ月 |
| 頻度 | 月1〜2回。年間18日程度 |
| フィールド | 六甲・金剛・比良などの関西の日帰り低山。年2〜3回、北アルプスや八ヶ岳へ遠征 |
| スタイル | 単独か、友人1〜2人。ツアーや山岳会には所属していない |
| 装備総額 | 約25〜30万円(ザック32L、レイン上下、3シーズンシューズ、テントは未所有) |
| アプリ | YAMAP(無料)、たまにヤマレコ |

### サイコグラフィック

- **駆動力は「次にいつ行けるか」。** 失敗したくないのは、失敗すると次の1回が潰れるから。
- スペック表は読む。ただし決め手は**実際に使い込んだ人の言葉**。数値だけでは踏み切れない。
- 映えや「山ガール」的なノリには乗らない。**静かな山、朝の空気、無心で歩く時間**に価値がある。
- 意識高い系のブランド語りは冷める。**作り手のこだわりを淡々と語られる**のには弱い。
- 自分を上級者だとは思っていない。だが「まずは高尾山から」はもう卒業した。
  **この中間層向けの情報が一番少ないことに苛立っている。**
- SNSは見る専。良い記事はXでこっそり保存する。

### 行動

- **検索はロングテール。** 「六甲 全山縦走 コースタイム 初回」のように条件を3語以上重ねる。
- **平日22:30〜24:30のスマホ、休日午前のPC。** 寝る前に比較記事を読む。
- 情報収集の順番: Google検索 → YouTube → YAMAPの活動日記 → 価格比較 → 店頭。
- 検討期間は2〜6週間。3万円超はセール(1月・7月)まで待つ。
- 記事は**目次から拾い読み**する。全文は読まない。
- ブックマークしない。**指名検索は起きにくい**ので、回遊で滞在を作る必要がある。

### Pain

- レビューがアフィリエイト目的にしか見えず、**悪い点が書いていないので信用できない**。
- スペックの数字が、実際の山でどう効くのか分からない。
- **関西の山の情報が少ない。** 検索するとアルプスと関東ばかり出てくる。
- 月1の機会を、天候と装備の失敗で潰したくない。
- 単独行が多く、安全面(道迷い・低体温症・エスケープ)に漠然とした不安がある。

### Goal

- 短期: 次の遠征までに、レインウェアとヘッドランプを決着させる。
- 中期: 「これで揃った」と言える一式を作り、買い物の悩みから解放される。
- 長期: **40代・50代になっても、このペースで山にいる。** いつかテント泊縦走をしたい。
- 感情面: 「ちゃんと調べて選んだ」という納得。人に説明できる状態。

### 意思決定要因(重い順)

1. 同じ人が長期間使い続けているか(単発レビューは信じない)
2. 悪かった点が具体的に書いてあるか
3. 実測値(カタログ重量ではなく、自分で量った重量)
4. 雨・寒さ・汗など、悪条件での挙動
5. 価格と値引きのタイミング
6. 日本人の体型に合うか
7. 修理・保証・サポート
8. 誰が書いたか(プロフィールに実体験が見えるか)

### タッチポイント

| チャネル | 役割 | 温度 |
|---|---|---|
| Google検索 | 流入の8割。ロングテールの比較・ハウツー | 冷 |
| YouTube | 実機の動きを確認 | 中 |
| YAMAP / ヤマレコ | 他人の実使用を確認 | 中 |
| X | 二次的な情報収集、保存 | 低 |
| Instagram | ブランドと山の雰囲気の発見 | 低〜中 |
| 実店舗(好日山荘 / mont-bell / Alpen) | 最終確認と購入 | 高 |

|---|---|

## 4. Editorial Policy(記事の約束)

Value ではなく、ここが記事の運用ルール。

1. **使ってから書く。** 天候と季節を変えて、最低3回。
2. **数字は自分で量る。** カタログ値ではなく実測値。違えば違うと書く。
3. **合わなかった点を同じ分量で書く。** これがない記事は、P1にとって広告と同義。
4. **関西の固有名詞を出す。** 六甲・金剛・比良・大峰。検索とリアリティの両取りになる。
5. **目次で拾い読みできる構成にする。** P1は全文を読まない。
6. **書きっぱなしにしない。** 使い続けて印象が変わったら記事を更新する。
7. **記事の最後に「次に読む1本」を置く。** 指名検索が起きにくい層なので、回遊で滞在を作る。

## 5. コピーの基準

### 書き方

- 主語は「次に行く日」。道具の話も、**出発の準備**として書く。
- 一文を短く。説明を足すより、言い切って止める。
- 具体名詞(山名・数字・条件)を必ず1つ入れる。抽象語だけの文を作らない。
- **Mission の語彙**(ベースキャンプ、荷、天候、一歩、出ていく)を核に置く。

### 使わない語

- 最強 / コスパ最強 / 初心者必見 / 保存版 — P1が一番冷める語
- 登山家 / アドベンチャー — 距離を感じさせる
- 他ブランドの批判、盛った実績、資格の匂わせ(E-E-A-T上もリスク)

### 運営者プロフィールで証明すること

1. **同じ制約を持っていること。** プロではなく、働きながら月1〜2回登り続けている人。
2. **同じフィールドを歩いていること。** 関西の山の固有名詞を3〜4。
3. **検証の視点があること。** 感想文ではなく検証であるという宣言。
4. **作り手であること。** S2に効く。ただしブランドの話は最後に一行で足りる。
